# IT Asset Management System

A mid-level IT operations project concept for tracking company devices, assignments, maintenance history, and support status.

## Project Overview

The goal of this system is to help an IT team manage laptops, desktops, printers, routers, and other workplace assets from one organized dashboard.

## Core Features

- Asset inventory with device type, serial number, status, and location
- User assignment history for laptops and accessories
- Maintenance and repair logs
- Warranty and purchase date tracking
- Support ticket reference for each asset
- Search and filter by department, status, or device type
- Dashboard summary for active, damaged, retired, and available assets

## Suggested Tech Stack

- Frontend: React or HTML/CSS/JavaScript
- Backend: Node.js / Express or Django
- Database: PostgreSQL or MySQL
- Authentication: Role-based login for admin and support staff

## Main Modules

- Asset Registry
- User Assignment
- Maintenance Logs
- Reports Dashboard
- Admin Settings

## Learning Goals

This project is designed to demonstrate practical understanding of IT operations, database design, CRUD workflows, and clean technical documentation.

## Future Improvements

- Barcode or QR code scanning
- CSV import/export
- Email alerts for warranty expiry
- Role-based access control
- Analytics dashboard
